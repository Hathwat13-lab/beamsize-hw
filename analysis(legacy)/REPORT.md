## 3. 주파수별 w(f): 복소 스펙트럼 선형 혼합 모델

이번에 새로 쓴 방법입니다. 기존 게이팅과 FFT 방식의 한계를 피하려고 만들었습니다.

$$\boxed{E_{ij}(f)=F_{ij}(f)\,R_1(f)+\bigl(1-F_{ij}(f)\bigr)R_2(f)}$$

- R1은 칩 중앙(11×11 픽셀) 평균 스펙트럼입니다. R2는 개방 코너 평균 스펙트럼입니다.
- 에지 픽셀의 코히런트 신호는 "칩 반사 + 개방 반사"를 빔이 덮는 비율 F로 선형 보간한 값입니다.
- 윈도우(Tukey α=0.2, 전 픽셀 동일)와 FFT가 선형이라, 게이팅 없이 전체 50 ps 창을 그대로 씁니다. 그래서 게이트 분해능 제한(약 0.25 THz)이 없습니다.
- 픽셀과 주파수별로 d = R1−R2에 대한 최소제곱 사영으로 F를 구하고, F 맵에 erf를 피팅합니다.
- 기하(에지 위치·기울기)는 신뢰 빈에서 얻은 중앙값으로 고정합니다. w만 주파수별로 피팅하고, 라인별 A, B는 선형 소거합니다.

### 결과 (신뢰 빈: |R1−R2|/|R2| > 1, 0.35–1.5 THz, `table_wf_final.csv`)

| f [THz] | w_x [mm] | σ | w_y [mm] | σ |
|---|---|---|---|---|
| 0.5 | 2.48 | 0.17 | 2.32 | 0.18 |
| 0.6 | 2.12 | 0.15 | 1.74 | 0.22 |
| 0.8 | 1.70 | 0.12 | 1.32 | 0.11 |
| 1.0 | 1.44 | 0.03 | 1.08 | 0.06 |
| 1.2 | 1.30 | 0.16 | 0.92 | 0.03 |
| 1.4 | 1.25 | 0.42 | 0.84 | 0.15 |

(σ = 좌·우 또는 상·하 불일치와 피팅 범위 의존성을 합친 값입니다.)

- w_x ∝ f^−0.75, w_y ∝ f^−1.01입니다. w/λ는 x 방향 4.85 ± 0.56, y 방향 3.66 ± 0.17로, 거의 일정합니다(w ∝ λ에 가까움).
- 그림은 `figs/s4_wf.png`(전체 빈)와 `figs/s5_wf_final.png`(신뢰 빈 + 거듭제곱 피팅)입니다.

### 주의: 이 결과를 어디까지 믿을 수 있나

- **|R1−R2|는 0.222 THz(= 1/4.5 ps) 간격으로 마디가 생깁니다.** 두 경로가 동위상이면 칩과 개방을 구분할 수 없기 때문입니다. 마디 근처에서는 모델 오차가 증폭되어 w가 톱니 모양으로 튑니다. 그래서 마디에서 먼 빈만 썼습니다.
- **모델 위반이 잡음보다 큽니다.** E가 R1–R2 직선에서 벗어나는 수직 성분이 잡음의 3–4배입니다. 원인은 아직 모릅니다. 가능한 원인은 개방 배경의 공간 변화, 에지 회절 위상, 칩 반사의 비균일성입니다.
- **0.4 THz 이하**는 w가 3 mm 이상으로 크고(칩 반폭 3 mm 이상), erf 모델이 깨져서 발산합니다.
- **1.5 THz 초과**는 신호가 작아서(2 THz에서 약 6 %) 불안정합니다.
- 좌·우 에지의 불일치가 커지는 빈이 있습니다(1.4 THz에서 0.95 대 1.54). 기하(기울기·위치)의 고정이 완벽하지 않다는 뜻입니다.

## 4. 가우시안 가정, early와 late, 초점면

- **전이 곡선 미분(LSF) 첨도**(가우시안 = 3): 좌 3.06, 우 2.97, 상 3.31, 하 3.70. 좌·우는 가우시안에 잘 맞습니다. 상·하는 꼬리가 조금 무거워서(특히 하) 가우시안에서 벗어납니다.
- **early(a)와 late(b)**: 에지별로 w 차이가 약 5 %이고, 항상 b가 큽니다. 게이트 꼬리 누설과 템플릿 오차 범위 안입니다.
- **초점면 차이**: 레일리 거리 z_R = πw²/λ가 0.5 THz에서 약 30 mm, 1 THz에서 약 18 mm입니다. Si 두께 0.675 mm는 이의 2–4 %라서 상면 반사와 하면 반사(late)의 초점 차이는 무시할 수 있습니다.

## 5. 한계와 다음에 볼 만한 것

1. 에지 기하(기울기, 위치)가 흔들립니다. 단순 사각형 대신 **회전한 정사각형 전체를 가우시안으로 블러한 2D 전방 모델**을 전 픽셀에 피팅하면 코너와 4변이 한꺼번에 맞춰지고 기하도 안정됩니다. 제안만 하고 만들지는 않았습니다.
2. 모델 위반의 원인을 알아봐야 합니다. 개방 배경을 코너 평균 하나로 두었는데, 위치에 따라 R2가 달라지는지(1–2 % 수준의 pp 변화가 보입니다) 확인이 필요합니다.
3. 상·하 에지의 꼬리 무게는 칩 에지 모서리(금 가장자리 모양)나 비가우시안 빔 때문일 수 있습니다.
4. Y 부호와 X-fast 가정은 여전히 데이터만으로는 검증하지 못했습니다. 원본 GUI 스크린샷이나 칩 배치와 대조가 필요합니다.

## 6. 재현 방법과 산출물

실행은 FFT 폴더의 `.venv` 파이썬을 읽기 전용으로 썼습니다(설치·수정 없음). 순서대로 실행하면 됩니다.

```
cd analysis/scripts
python s1_load_maps.py   # 로드·캐시·맵
python s2_template.py    # 템플릿 최소제곱 a, b
python s3_edges.py       # 광대역 에지 피팅 (약 1.5분)
python s4_wf.py          # 주파수별 w(f) (약 1.5분)
python s5_summary.py     # 요약 표·그림, LSF, Rayleigh
```
